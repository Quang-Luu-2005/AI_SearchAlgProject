# FloodRoute HCMC - dataset submission v1.0.4

The normalized graph contains 65 landmark nodes and 283 directed aggregate road-path
edges. `LANDMARK_FLOOD` and `LANDMARK_CONGESTION` each apply an `ASSUMPTION`
override to 57 edges, approximately 20 percent of the graph. The hard-closure
scenario remains available for exact edge closure tests, while the frontend random
scenario generates temporary edge conditions for the selected route.

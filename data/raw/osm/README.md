# OSM snapshots

- `thu_duc_osm_v1.0.0/`: Snapshot Overpass API ngày 2026-08-10 cho bbox Chợ Thủ Đức (10.845-10.853, 106.751-106.759). Bao gồm `osm_road_snapshot.json`, `source_registry.json` và `checksums.sha256`.

Mỗi lần trích xuất cần một thư mục dạng `YYYY-MM-DD_<area>/` chứa file gốc,
query/bbox hoặc polygon, ngày trích xuất, phiên bản OSMnx và attribution ODbL.
Không dùng dữ liệu tải trực tiếp theo thời gian thực trong demo chính.

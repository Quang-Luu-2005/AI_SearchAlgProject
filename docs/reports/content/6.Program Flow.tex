\subsection{Luồng Xử lý Tìm kiếm 2 Điểm (Two-Point Search Workflow)}
Khi người dùng thực hiện tìm đường trên giao diện:
\begin{enumerate}[leftmargin=1.5cm]
    \item \textbf{Khởi tạo Yêu cầu}: Người dùng chọn điểm Start, Goal (qua click map hoặc tìm kiếm), chọn Kịch bản (vd: Mưa lớn) và Thuật toán (vd: A*).
    \item \textbf{Gửi API Request}: React gửi request \texttt{POST /api/v1/search} đến FastAPI Backend.
    \item \textbf{Xác thực \& Điều phối}: \texttt{SearchService} nạp graph từ catalog, áp dụng kịch bản qua \texttt{GraphView} và gọi hàm thuật toán tương ứng.
    \item \textbf{Tính toán \& Ghi nhận Trace}: Thuật toán duyệt đồ thị, tính chi phí cạnh qua \texttt{ScenarioCostEngine} và sinh danh sách \texttt{TraceEvent} (\texttt{OPEN}, \texttt{EXPAND}, \texttt{RELAX}, \texttt{CLOSE}, \texttt{GOAL}).
    \item \textbf{Giải thích Tuyến đường}: \texttt{ExplanationEngine} phân tích thành phần chi phí chiếm ưu thế và xác định đoạn đường có penalty kẹt xe/ngập lớn nhất.
    \item \textbf{Hiển thị Trực quan}: React vẽ đường đi tối ưu lên bản đồ vector và kích hoạt \textbf{Trace Player} cho phép người dùng xem lại toàn bộ quá trình mở rộng nút.
\end{enumerate}

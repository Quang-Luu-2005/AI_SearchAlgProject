# Documentation map

| Tài liệu | Mục đích | Khi nào cập nhật |
|---|---|---|
| `architecture.md` | Module, luồng dữ liệu, API contract | Khi đổi boundary hoặc interface |
| `data-management.md` | Vòng đời, schema, provenance, QC | Mỗi thay đổi dataset/pipeline |
| `project-brief-and-trello-plan.md` | Tóm tắt đồ án và kế hoạch Trello 7 ngày cho 4 người | Khi đổi sprint goal, phân công hoặc trạng thái nền |
| `documentation-workflow.md` | Definition of Done cho docs | Khi đổi quy trình nhóm |
| `decisions/` | Lý do và trade-off của quyết định | Khi có quyết định kiến trúc đáng kể |
| `progress/` | Việc đã làm, bằng chứng, bước tiếp | Sau mỗi bước triển khai |
| `references/` | Tài liệu nguồn ban đầu | Chỉ thêm nguồn, không sửa nội dung |

`README.md` ở root là điểm bắt đầu và phải phản ánh đúng trạng thái hiện tại.
